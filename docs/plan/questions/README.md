# Въпроси към собственика

Когато етап Mxx спре по условие от „Кога да спре и да попита“ и няма документирано решение по подразбиране, нишката записва въпроса в `docs/plan/questions/Mxx.md`, прави commit и push и отпечатва `BLOCKED Mxx: <причина на един ред>` (план §8.2, `docs/plan/RULES.md`).

Въпросите са **на английски**. Всеки въпрос има този формат:

```markdown
## <YYYY-MM-DD> — Mxx — <short title>

**Question:** …

**Options:**
1. …
2. …

**Proposed default:** …

**Answer:** (filled in by the owner)
```

Командите, пътищата и точните низове се пишат дословно. Собственикът отговаря в същата нишка или в полето **Answer** във файла на клона, а работата продължава със същия ред `/goal`.
