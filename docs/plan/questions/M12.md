# M12 — questions for the owner

M12 did not stop on any of these questions. Each one keeps its proposed default, marked in the code or the docs, until the owner answers it.

## 2026-11-01 — M12 — The pilot's availability target and support response time (D24)

**Question:** the technical plan (§10.1, D24) leaves the pilot's availability target and the support response time to M12, for the owner to confirm. Which targets apply to the local pilot?

**Options:**
1. **Best-effort availability (the app runs when the owner has started it for a pilot session; planned stops announced beforehand); a reply within 2 working days to a question or report, within 1 working day to a fault that stops a participant, and within 24 hours (weekends included) to a suspected data leak or breach; RPO up to the last local archive; RTO up to 4 hours.**
2. The same with shorter replies (for example 1 working day and 4 hours), which needs someone besides the owner on call.
3. Fixed pilot hours (for example weekday evenings) during which the app is promised to run, with replies within those hours.

**Proposed default:** option 1 (`docs/operations/incident.md`, `docs/operations/backup-and-restore.md`, `scripts/restore-drill.sh`: `DEFAULT D24`). The GDPR deadline for notifying the supervisory authority of a personal data breach (72 hours, Article 33) applies whatever the choice.

## 2026-11-01 — M12 — How often the local archive is made

**Question:** until hosting, the recovery point of the pilot is the last local archive (D24). Should `scripts/backup-local.sh` run on a schedule, and how often?

**Options:**
1. **By hand: daily on days with changes and always before an update; the admin guide shows a cron line for WSL2 that the owner can turn on.** `/admin/system` shows the time of the last archive.
2. A daily cron job set up as part of the pilot's start (WSL2 runs cron only while the distribution is running, so it is not a guarantee on Windows).
3. An archive by the app itself (a pg-boss job): needs pg_dump inside the app image at the server's version, which M12 avoided.

**Proposed default:** option 1 (`docs/operations/backup-and-restore.md`, "Колко често").
