## 2026-10-17 — M00b — Colour of "Verified"

**Question:** the Ink Lineage prototype stamps verified links with a red seal; plan §5.2 makes `--verified` green (`#00E676`) and reserves red for the primary button. Which colour should "Verified" use?

**Options:**
1. Jade green: `#45D98F` in the dark theme, `#0A6E43` in the light theme. Red stays for the brand mark and the primary action only.
2. Red seal, as in the prototype: red then means both the brand and "verified".
3. The plan's `#00E676` (dark) with a darker green for the light theme.

All three pass the contrast checks in `src/design/contrast.test.ts`, and the state is always shown by stroke, seal and text as well, never by colour alone.

**Proposed default:** option 1, jade green (recorded in `docs/adr/0006-design-system.md`).
